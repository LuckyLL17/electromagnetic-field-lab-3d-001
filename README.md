# ElectroMag Lab · 3D

基于 React、Vite、TypeScript、Three.js 与 React Three Fiber 的专业 3D 可视化实验平台。

## 启动

```bash
npm install
npm run dev
```

开发端口：`5176`。

## 实验会话（Experiment Session）

在侧栏「实验会话 · 检查点时间轴」面板中，可以把当前实验状态记录为**不可变检查点**并在时间轴上回放：

- **检查点内容**：场型（电偶极子 / 螺线管 / 平行板电容器）、激励强度、场矢量开关、相机位置与 OrbitControls 注视点。捕获时做深拷贝并递归冻结，与捕获之后的实时 React state / THREE 对象完全脱钩。
- **时间轴回放**：播放 / 暂停 / 继续 / 取消 / 中断 / 逐点跳转。取消会原子恢复到按下播放前的实时画面；中断则停在当前帧。播放/暂停期间控制区与场景控件锁定，避免与回放竞争。
- **原子恢复**：恢复检查点时相机先就位、控制区在同一 React 批处理任务中写入，二者之间不存在“控件是 A、场景是 B”的中间渲染；任一步失败都会回滚到调用前画面。
- **JSON 导入 / 导出**：导出为带 `kind` / `version=1` 头的 JSON 文件；导入时先整体解析校验，**通过后才触碰任何现有状态**——坏 JSON、未知版本、非法结构、首帧无法应用都会被拒绝，当前实验、播放状态与定时器均不受影响。
- **资源卫生**：导出使用的 Blob URL 经统一登记，延迟吊销并在组件卸载 / 会话销毁时兜底回收；回放定时器带代数标记，取消、中断、销毁后迟到的回调不会生效，不残留定时器。
- **严格拒绝 / 兼容读取**：未知 `version`、错误 `kind`、非法枚举/数值/布尔一律严格拒绝；缺失的 `id` / `label` / `t` / 名称等可选字段按规则合成，未知的额外字段忽略。

## 测试

核心会话逻辑（编码解码、原子恢复、回放引擎、URL 生命周期、编排器）与 React / Three 解耦，可用 Node 内置测试运行器验证：

```bash
npm test
```

测试使用注入式假时钟，不依赖真实定时器或浏览器环境，覆盖：回放/暂停/继续/取消/中断/跳转、迟到定时器作废、坏文件与未知版本拒绝、重新导入原子替换、失败回滚与恢复、对象 URL 回收等场景。

项目前端基础实验流程之外，后续可扩展真实 CFD / FEM 数据导入、网格解析、测量工具和实验结果导出。
